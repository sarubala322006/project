# AI-Based Crop Recommendation System

## About the Project
A Machine Learning application that recommends suitable crops based on soil nutrients and environmental conditions.

## Technologies Used
- Python
- Machine Learning
- Random Forest Classifier
- Streamlit
- Pandas
- Scikit-learn

## Input Parameters
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- Soil pH
- Rainfall

## Features
- Crop recommendation
- Top 3 crop predictions
- Prediction confidence
- Crop information
- Prediction history
- Downloadable prediction report
- Feature importance visualization

## How to Run

1. Install the dependencies:

   `pip install -r requirements.txt`

2. Run the application:

   `streamlit run app.py`

## Model
Random Forest Classifier

The application reports a test accuracy of 99.32%; this should be verified against the actual model evaluation results.
